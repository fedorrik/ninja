# Проверки сборки

## Выполнено

- 28 автоматических тестов — успешно.
- В составе тестов: 100 полных партий «Секретного Гитлера» и 80 полных партий «Ночи ниндзя» с автоматическими решениями игроков.
- Проверены скрытые роли и руки, одновременные голоса/выбор карт, запрет повторного и устаревшего хода, порядок ночных действий, реакции, трикстеры, награды и победы, все президентские способности, вето, хаос, ограничения назначения канцлера.
- HTTP-проверка отдельного сервера с пятью участниками: создание комнаты, вход, начало, выбор правительства, голосование, закрытая передача законов, отклонение неверного токена, восстановление точно той же руки после перезапуска процесса — успешно.
- JavaScript прошёл проверку синтаксиса Node.js.
- Установщик прошёл `bash -n`.
- В браузере проверены упрощённый каталог, рисунки, создание комнаты, лобби и выход.

- Затем добавлены одобренные иллюстрации обеих игр; их файлы и маршруты включены в сборку.

- Проверена приватность журнала: результаты просмотра, тайное решение Оборотня, выбор Могильщика и значения жетонов не попадают в общие события; голоса и выбранные карты раскрываются только после готовности всех.

- Новый запуск `start_lan.py` проверен HTTP-тестом с пятью клиентами и восстановлением партии после перезапуска. Подключение с реальных телефонов через ваш роутер и Windows BAT-запуск в этой среде не проверялись.

## Границы проверки

- На реальном чистом VPS установщик не запускался: машины и домена для развёртывания не было.
- Docker в среде отсутствует, сборка контейнера и получение TLS-сертификата не проверялись.
- Не проводились нагрузочный тест, отдельный аудит безопасности, полная ручная партия в нескольких браузерах и проверка на физических телефонах.
- Автоматические партии проверяют завершение и инварианты механики, а не стратегию игроков и не заменяют совместную пробную партию.

## Повторить

```bash
python3 -m unittest discover -s tests -v
python3 tests/http_smoke.py
```

HTTP-тест запускает собственный сервер на свободном локальном порту, использует временную базу и удаляет только свои временные данные. Для него нужна возможность открывать локальные сетевые соединения.
